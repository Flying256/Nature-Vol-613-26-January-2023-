## 混淆矩阵解释

重点检查 M6/M8 和 M11/M12/M14。当前 `tp6_noise0` 混淆矩阵已观察到 `M6->M8 = 795`、`M8->M6 = 917`、`M11->M14 = 1252`、`M14->M11 = 2011`、`M12->M14 = 396`、`M14->M12 = 506`。若这些机理成组出现，不应直接视为复现失败，因为论文说明这些机理在部分动力学空间中存在重叠。第二层完成时应结合 top-1 confusion matrix 和 99% grouping 覆盖情况解释：当前 `tp6_noise0` 上 `M6`、`M8`、`M11`、`M12`、`M14` 五类样本的 99% grouping 覆盖率均为 `1.000000`，因此这些误判更应解释为动力学空间重叠，而不是单纯模型错误。
