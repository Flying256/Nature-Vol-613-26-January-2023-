# Nature 613 复现执行说明

本目录用于复现 Nature 613 论文 `Organic reaction mechanism classification using machine learning` 的第一层和第二层。第一层运行作者公开的预测代码、训练好权重、示例动力学数据和 case study 数据；第二层使用作者训练好的主模型和官方测试集复核 top-1、top-3、99% grouped accuracy、噪声鲁棒性、时间点数量影响和混淆矩阵。本阶段不在当前设备执行完整训练。

## 官方资源

模型和代码包 DOI 为 `10.48420/16965271`，file id 为 `38936852`，直接下载 URL 为 `https://figshare.manchester.ac.uk/ndownloader/files/38936852`，本地文件放在 `official/AI_model_and_files.zip`，解压后目录为 `official/AI_model_and_files/`。训练、验证和测试集 DOI 为 `10.48420/16965292`，file id 为 `38936666`，直接下载 URL 为 `https://ndownloader.figshare.com/files/38936666`，官方文件名为 `M1_M20_train_val_test_set.zip`，大小 `7080099735` bytes，MD5 `9c52b6f31aaf450be570663cfb283f2a`，本地文件放在 `official/M1_M20_train_val_test_set.zip`。旧文档里写过的 `TrainValTest.zip` 只作为兼容别名保留。

下载和检查资源：

```bash
PYTHONPATH=src python3 scripts/download_or_explain.py --attempt
PYTHONPATH=src python3 scripts/inspect_resources.py
```

如果 7GB 数据包下载中断，重复上面的 `download_or_explain.py --attempt` 或直接执行下面命令即可续传：

```bash
curl -L --continue-at - --retry 10 --retry-delay 5 --fail \
  --output official/M1_M20_train_val_test_set.zip \
  https://ndownloader.figshare.com/files/38936666
```

解压资源：

```bash
PYTHONPATH=src python3 scripts/unpack_official_archives.py --resource model_package
PYTHONPATH=src python3 scripts/unpack_official_archives.py --resource dataset_package
```

`dataset_package` 使用的 ZIP 可能是 Deflate64，脚本已经在 Python `zipfile` 不支持时 fallback 到系统 `unzip`。

## 第一层运行

官方代码要求旧版 Keras/TensorFlow 环境。推荐用本项目 Docker 镜像运行，而不是在当前 macOS Python 里直接运行：

```bash
docker build --platform linux/amd64 \
  -f docker/Dockerfile \
  -t nature613-kinetics-train:latest .
```

由于 `.dockerignore` 不把 `official/` 打入镜像，运行验证容器时需要挂载或复制官方模型目录。当前环境 Docker bind mount 有异常时，可用 `docker cp`：

```bash
docker rm -f nature613-run || true
docker create --platform linux/amd64 --name nature613-run \
  nature613-kinetics-train:latest sleep infinity
docker start nature613-run
docker exec nature613-run mkdir -p /workspace/official /workspace/artifacts /workspace/outputs
docker cp official/AI_model_and_files nature613-run:/workspace/official/AI_model_and_files
```

检查环境、运行示例和导出 M1-M20 概率：

```bash
docker exec -w /workspace nature613-run python scripts/inspect_environment.py
docker exec -w /workspace nature613-run bash scripts/run_official_prediction.sh
docker exec -w /workspace nature613-run python scripts/export_text_probabilities.py \
  --output artifacts/kinetics_probabilities.csv
```

已验证 `Data/kinetics.txt` 输出 `M1`，完整概率 CSV 中 `M1=0.997760772705`，99% 候选组为 `M1`。

批量运行 case study：

```bash
docker exec -w /workspace nature613-run bash scripts/run_case_studies.sh
```

已验证输出为：Case 1 `M12 M17`，Case 2 `M14 M16`，Case 3 `M10 M15`，Case 4 `M7`，Case 5 `M6 M8`，Case 6 Ph `M10 M11 M14 M15 M20`，Case 6 Me `M4 M5 M10 M11 M15 M16`。

## 第二层评估

第二层既可以等待 `official/M1_M20_train_val_test_set.zip` 完整下载并解压，也可以直接先抽取测试子集来做评估。如果整包尚未完成，先运行：

```bash
PYTHONPATH=src python3 scripts/fetch_test_subset.py \
  --archive official/M1_M20_train_val_test_set.zip \
  --output-zip official/test_subset.zip

mkdir -p official/test_subset
unzip -o official/test_subset.zip -d official/test_subset
```

官方 `README` 已确认 `x2_test` 的结构不是单一数组，而是嵌套字典：`x2_test[timepoints][noise]`。当前公开测试分支为 `(20,1)`、`(6,0)`、`(6,1)`、`(6,5)` 和 `(2,1)`。如果整包已解压，先检查真实文件名：

```bash
find official/M1_M20_train_val_test_set -maxdepth 3 -type f | sed -n '1,120p'
```

如果测试集已经整理成显式 `.npy` 输入，可以运行：

```bash
PYTHONPATH=src python3 scripts/predict_test_set.py \
  --model official/AI_model_and_files/Data/M1_20_model.h5 \
  --data-dir official/test_subset \
  --timepoints 6 \
  --noise 0 \
  --output artifacts/tp6_noise0_probabilities.npy \
  --labels-output artifacts/tp6_noise0_labels.npy

PYTHONPATH=src python3 scripts/evaluate_predictions.py \
  --probabilities artifacts/tp6_noise0_probabilities.npy \
  --labels artifacts/tp6_noise0_labels.npy
```

当前仓库已经适配官方 `.pkl` 结构，不需要再手工转 `.npy`。实测表明，论文正文里的主指标对应的是 `(6,0)` 分支，而不是 `x2_test[20][1]`：`(6,0)` 的 top-1 accuracy 为 `0.926390`，top-3 accuracy 为 `1.000000`，99% grouped accuracy 为 `0.999620`；`(20,1)` 分支的 top-1 为 `0.891460`。因此复核论文核心表述时，应默认把“标准测试集”解释为 `6` 个时间点、`0%` 噪声这一官方测试分支。

多个噪声/时间点变体可以通过 manifest 批量评估：

```bash
PYTHONPATH=src python3 scripts/evaluate_variants.py \
  --manifest artifacts/variants.yml \
  --output-dir artifacts/evaluation
```

该脚本输出 `variant_summary.csv` 和每个变体的 confusion matrix。当前实测结果为：`tp6_noise0` 的 top-1 `0.926390`、`tp6_noise1` 的 top-1 `0.860170`、`tp6_noise5` 的 top-1 `0.505840`、`tp2_noise1` 的 top-1 `0.716500`、`standard_tp20_noise1` 的 top-1 `0.891460`。解释 M6/M8、M11/M12/M14 时，重点看真实标签是否落在 99% candidate group 内；在 `tp6_noise0` 上，这五类样本的 99% 分组覆盖率均为 `1.000000`，因此如果 top-1 在这些机理之间转移，应视为与论文所说的动力学空间重叠一致，而不是单纯模型错误。

## Docker 训练入口

镜像只包含 Python、TensorFlow、SciPy、NumPy、pandas、scikit-learn、matplotlib、pycm、本项目脚本和训练入口，不包含 7GB 训练数据、官方 `.h5` 或输出目录。训练数据和输出必须通过 volume 挂载。训练入口默认拒绝运行，必须显式设置 `NATURE613_ALLOW_TRAINING=1`：

```bash
docker run --rm --platform linux/amd64 \
  -e NATURE613_ALLOW_TRAINING=1 \
  -v /data/M1_M20_train_val_test_set:/workspace/Data \
  -v /path/to/AI_model_and_files:/workspace/official/AI_model_and_files \
  -v /outputs/nature613:/workspace/outputs \
  nature613-kinetics-train:latest \
  python scripts/train_entrypoint.py \
    --train-script official/AI_model_and_files/train.py \
    --data-dir Data \
    --output-dir outputs
```

只检查入口不训练：

```bash
docker run --rm --platform linux/amd64 \
  -e NATURE613_ALLOW_TRAINING=1 \
  nature613-kinetics-train:latest \
  python scripts/train_entrypoint.py --dry-run
```

如果要在本地用整个仓库挂载到 `/workspace` 的方式运行预测或评估，必须额外显式挂载 `official`，因为镜像声明了 `VOLUME /workspace/official`，否则 Docker 会给 `official` 创建匿名卷并遮住本地模型文件。可用命令形式如下：

```bash
docker run --rm --platform linux/amd64 \
  -v /absolute/path/to/nature613_repro:/workspace \
  -v /absolute/path/to/nature613_repro/official:/workspace/official \
  nature613-kinetics-train:latest \
  python scripts/predict_test_set.py \
    --model official/AI_model_and_files/Data/M1_20_model.h5 \
    --data-dir official/test_subset \
    --timepoints 6 \
    --noise 0 \
    --output artifacts/tp6_noise0_probabilities.npy
```
